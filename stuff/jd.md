Key Responsibilities
Kubernetes Operations: Take hands-on responsibility for the daily health, performance, and reliability of the client's production Kubernetes clusters. Handle troubleshooting, scaling, and maintenance.
Automation & Scripting: Write maintainable and effective scripts in Python, Bash, or PowerShell to automate repetitive operational tasks, fix recurring issues, and reduce manual toil.

CI/CD Pipeline Support: Maintain and improve CI/CD pipelines (e.g., GitLab CI, Jenkins, GitHub Actions, or ArgoCD) to ensure smooth and secure application deployments.
Migration Execution: Work with the consulting team and client to assess legacy systems. When the project scope expands, actively participate in migrating applications and infrastructure into Kubernetes.
Client Communication: Act as a reliable technical point of contact for the client. Clearly communicate operational status, issues, and improvements to both technical and non-technical stakeholders.
Security & Compliance: Follow strict security practices required in the financial sector, including managing RBAC, network policies, and secure secrets handling.

Terraform: Practical experience using Terraform to manage infrastructure as code.
CI/CD: Experience building, troubleshooting, or maintaining CI/CD pipelines.
Code-Augmented LLM Experience: Practical experience utilizing Large Language Models (LLMs) to augment coding and operational workflows (e.g., using GitHub Copilot, ChatGPT, or similar AI coding assistants) to accelerate script development, troubleshoot infrastructure issues, and optimize code.
Migration Experience: Previous experience participating in infrastructure or application migrations (e.g., moving VMs to containers, or migrating between cloud environments).
Consulting Skills: Good communication skills and the ability to work professionally within a large, heavily regulated enterprise environment.
